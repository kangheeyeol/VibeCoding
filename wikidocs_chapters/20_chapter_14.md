## 2. 💡 [1분 개념] '수석 건축가'와 '현장 조수'의 분업
집을 지을 때 현관문 페인트칠을 하거나 타일 줄눈을 맞추는 사소한 일에 **시급 100만 원짜리 수석 건축가**를 부르면 파산합니다.
- 🧠 **수석 건축가 (Claude 3.7 Sonnet / GPT-4.5)**: 
	- 집의 기초 설계, 복잡한 데이터베이스 구조, 원인 모를 심각한 버그 해결에만 투입합니다.
- ⚡ **손 빠른 현장 조수 (Claude 3.5 Haiku / Gemini 2.5 Flash)**: 
	- 버튼 색상 변경, 텍스트 오타 수정, CSS 간격 조정, 주석 달기 같은 단순 노동에 투입합니다.

## 4. 📋 비개발자 지갑을 지키는 3대 실무 수칙
### 수칙 1. Cursor 모델 드롭다운을 확인하는 습관 들이기
Cursor 채팅창 하단 모델 선택창에서 평소 가벼운 UI 작업이나 질문을 할 때는 **`Flash`****나 ****`Haiku`**로 맞춰두고, 정말 중요한 로직을 짤 때만 **`Sonnet`**으로 스위칭하세요. 이것만으로도 월 사용량을 5배 이상 늘릴 수 있습니다.
### 수칙 2. 한 번에 질문 하나만 하기
욕심을 내서 *"로그인도 만들고, 잔디도 그리고, 프로필 사진도 바꾸고, 폰트도 키워줘"*라고 한 번에 4가지를 물어보면 AI는 긴 답변을 하느라 대량의 토큰을 쓰고 중간에 코드가 잘립니다.  
**"1프롬프트 = 1기능"** 원칙을 지키세요.
### 수칙 3. 0원으로 완주하는 무료 코스 팁
- Cursor는 매달 2주간의 무료 Pro 체험과 무료 크레딧을 제공합니다.
- Gemini API 키를 개인 발급(Google AI Studio에서 무료 발급 가능)받아 Cursor에 연결하면, 일일 수십만 토큰을 완전 무료로 쓸 수 있습니다!
