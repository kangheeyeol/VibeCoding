# Chapter 10-1. [공식 실습] 'Use this template' 클릭 한 번으로 나만의 루틴메이트 저장소 만들기
## 1. 🎯 [디렉터 브리핑] 이번 챕터 미션
- 빈 폴더에서 복잡하게 패키지를 설치하다가 중도 포기하지 않도록, **미리 완벽하게 시공된 공식 스타터 템플릿**을 클릭 한 번으로 내 계정에 복사합니다.
- 내 컴퓨터의 Cursor로 프로젝트를 열고, 로컬 서버(`localhost:3000`)를 띄워 첫 화면을 확인합니다.
---
## 2. 💡 [1분 개념] '빈 땅에 맨손 벽돌 쌓기' vs '모델하우스 열쇠 받기'
초보자가 빈 폴더를 만들고 처음부터 Next.js, Tailwind, 폰트 설정을 하려고 하면 100% 버전 충돌 에러를 만나 좌절합니다.
우리가 제공하는 공식 스타터 킷은 **이미 수도, 전기, 가구가 완벽하게 빌트인된 '모델하우스의 마스터키'**를 건네받는 것과 같습니다.  
여러분은 열쇠만 꽂고 들어가서 가구 위치(디자인)를 바꾸고 나만의 루틴(기능)을 추가하기만 하면 됩니다!
---
## 3. 📋 [실습] 3단계로 끝내는 공식 템플릿 복제 및 실행
### 1단계: GitHub에서 내 계정으로 템플릿 복제하기
1. 웹 브라우저에서 공식 실습 저장소 링크에 접속합니다:  
	🔗 [**루틴메이트 공식 GitHub 저장소 바로가기**](https://github.com/kangheeyeol/VibeCoding)
2. 화면 우측 상단에 있는 초록색 **`[Use this template]`** 버튼을 클릭하고 **`Create a new repository`**를 선택합니다.
3. **Repository name**에 `my-routinemate`라고 적고, **`Create repository`**를 누르면 끝! (단 3초 만에 내 계정으로 완벽한 프로젝트가 복사됩니다.)
---
### 2단계: Cursor에서 내 프로젝트 열기
1. 내 깃허브 저장소 화면에서 초록색 **`[ <> Code ]`** 버튼을 누르고 주소를 복사합니다.
2. **Cursor** 프로그램을 엽니다.
3. 상단 메뉴에서 **`File`**** **$`\rightarrow`$** ****`Open Folder...`** (또는 시작 화면의 `Clone Repository`)를 선택하여 방금 복제한 프로젝트 폴더를 엽니다.
---
### 3단계: 로컬 서버 켜고 내 눈으로 확인하기
1. Cursor 상단 메뉴에서 **`Terminal`**** **$`\rightarrow`$** ****`New Terminal`**을 클릭합니다. (화면 아래에 카톡 창 같은 터미널이 열립니다.)
2. 마법의 주문을 입력하고 엔터를 칩니다:
	```bash
npm run dev
	```
3. 몇 초 뒤 터미널에 `Ready in 1500ms` 같은 초록색 글씨가 뜨면 성공입니다!
4. 브라우저를 켜고 주소창에 **`http://localhost:3000`** 을 입력하고 접속해 보세요.
---
## 4. 🔍 [탐색] 저장소에 기본 탑재된 3대 보물 파일 확인하기
열려 있는 Cursor 왼쪽 탐색기에서 다음 3개의 파일이 이미 예쁘게 들어 있는지 확인해 보세요:
1. 📜 **`.cursorrules`**:

2. 📋 **`SPEC.md`**: 
	- Part 2에서 우리가 확정했던 루틴메이트의 공식 기획서가 그대로 들어 있습니다.
3. 🔒 **`.env.example`**: 
	- 나중에 Part 7에서 Supabase 데이터베이스를 붙일 때 사용할 비밀 금고 양식입니다.

- [ ] 브라우저 주소창에 `http://localhost:3000`을 쳤을 때 깔끔한 루틴메이트 스타터 대시보드가 뜨는가?

이 3가지를 확인하셨다면, **축하합니다! 여러분은 이제 웹 툴의 한계를 벗어나 프로 개발자들과 동일한 최첨단 로컬 스튜디오를 손에 넣으셨습니다.**

## 6. 🚨 [비상 대응] 터미널에 `port 3000 is in use` 에러가 떠요!
- **원인**: 3000번 포트(가게 문)가 이미 다른 프로그램이나 이전 작업에 의해 열려있을 때 발생합니다.
- **해결법**: 
	1. 당황하지 마세요! Next.js는 자동으로 다음 번호인 `http://localhost:3001`로 가게를 열어줍니다.
	2. 터미널에 적힌 주소(`localhost:3001` 등)를 확인하고 그 주소로 브라우저에 접속하시면 정상 작동합니다.
