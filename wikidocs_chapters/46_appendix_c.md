# 부록 C. 터미널 3대 명령어 & Cursor 필수 단축키 치트시트
이 단축키와 명령어 몇 개만 손에 익혀두면 작업 속도가 5배 빨라집니다.
### 💻 비개발자 생존용 터미널 3대 명령어

| 명령어 | 뜻과 비유 | 언제 쓰는가? |
| --- | --- | --- |
| **`npm run dev`** | **"가스레인지 불 켜기"** (개발 서버 실행) | 작업을 시작할 때 내 컴퓨터 로컬 브라우저(`localhost:3000`)를 켤 때 |
| **`Ctrl + C`** | **"가스레인지 불 끄기"** (서버 강제 중지) | 실행 중인 서버를 멈추거나 터미널이 먹통이 되었을 때 |
| **`npm install`** | **"필요한 부품 일괄 배송받기"** | 프로젝트를 처음 클론받았거나 새 라이브러리 패키지를 설치할 때 |

> 🚨 **초특급 비상 탈출 명령어**:
> 코드가 도저히 수습할 수 없을 정도로 꼬였을 때 공식 완성본 스냅샷으로 1초 만에 강제 리셋:
> `git fetch origin && git reset --hard origin/snapshot-part-09`

### ⌨️ Cursor 에디터 핵심 단축키 7선

| 단축키 (Windows) | 단축키 (Mac) | 기능 및 디렉터의 활용법 |
| --- | --- | --- |
| **`Ctrl + L`** | `Cmd + L` | **AI 채팅창 열기**: AI와 새로운 기능 기획이나 버그 상담을 시작할 때 |
| **`Ctrl + I`** | `Cmd + I` | **Composer (전체 프로젝트 생성기)**: 여러 파일을 한꺼번에 만들고 고치게 할 때 |
| **`Ctrl + K`** | `Cmd + K` | **인라인 코드 수정**: 특정 코드 몇 줄만 드래그하고 "이것만 고쳐줘" 할 때 |
| **`Ctrl + Shift + G`** | `Cmd + Shift + G` | **소스 제어(Git) 창 열기**: 마우스로 커밋(세이브)하거나 되돌리기(Discard)할 때 |
| **`Ctrl + ~`** | `Cmd + ~` | **터미널 열기/닫기**: 에러를 확인하거나 `npm run dev`를 칠 때 |
| **`Ctrl + P`** | `Cmd + P` | **파일 초고속 검색**: 파일 이름을 타이핑해서 0.1초 만에 찾아 열 때 |
| **`Ctrl + Shift + P`** | `Cmd + Shift + P` | **명령 팔레트**: Cursor의 모든 숨겨진 기능과 설정을 검색할 때 |

### 🌐 브라우저 검수 필수 단축키
- **`F12`** (Mac: `Cmd + Option + I`): 크롬 개발자 도구 열기 / 닫기
- **`Ctrl + Shift + M`** (Mac: `Cmd + Shift + M`): 스마트폰 모바일 화면 시뮬레이터 켜기 / 끄기
- **`Ctrl + Shift + R`** (Mac: `Cmd + Shift + R`): 캐시를 완전히 날려버리는 강력 새로고침 (코드를 고쳤는데 브라우저가 안 바뀔 때)
