# 부록 B. 비개발자가 꼭 알아야 할 필수 웹/앱 개발 용어 사전 30선
개발자들과 대화하거나 AI에게 지시할 때 반드시 마주치게 되는 핵심 용어들을 비개발자의 눈높이에 맞춰 직관적인 일상 비유로 풀었습니다.
### [UI 및 프론트엔드 영역]
1. **프론트엔드 (Frontend)**: 레스토랑의 홀과 서빙 직원. 사용자가 눈으로 보고 손으로 터치하는 모든 시각적 화면.
2. **React (리액트)**: 페이스북이 만든 화면 레고 블록 공장. 화면 전체를 새로고침하지 않고 바뀐 레고 블록만 쏙 갈아 끼워주는 기술.
3. **Next.js (넥스트제이에스)**: 리액트 레고 블록에 엔진과 바퀴, 내비게이션(주소 라우팅)까지 달아 완성차로 만들어주는 최신 웹 프레임워크.
4. **컴포넌트 (Component)**: 재사용 가능한 레고 블록 하나. (예: 버튼 블록, 습관 카드 블록, 상단 바 블록).
5. **Props (프롭스)**: 부모 레고 블록이 자식 레고 블록에게 전달하는 '주문서'. (예: 카드 블록에게 "너는 제목에 '물 마시기'라고 써라" 하고 넘겨주는 데이터).
6. **State (상태)**: 화면이 기억하고 있는 현재의 기억. (예: "체크박스가 지금 켜져 있는가 꺼져 있는가?").
7. **Tailwind CSS (테일윈드)**: 미리 만들어진 예쁜 스타일 스티커 모음. 외계어 CSS 파일 대신 `text-red-500`, `p-4` 같은 스티커를 코드에 바로 붙여 디자인함.
8. **반응형 웹 (Responsive Web)**: 사용자의 기기 화면 크기(스마트폰, 태블릿, PC)에 따라 고무줄처럼 스스로 레이아웃을 최적화하는 웹사이트.
9. **렌더링 (Rendering)**: 코드로 적힌 설계도를 브라우저가 해석해서 우리 눈에 보이는 예쁜 그래픽 화면으로 그려내는 과정.
10. **스켈레톤 UI (Skeleton UI)**: 데이터를 인터넷에서 불러오는 동안 화면이 텅 비어 보이지 않게 회색 뼈대 박스가 펄럭거리며 로딩 중임을 알려주는 세련된 애니메이션.
### [데이터 및 백엔드 영역]
1. **백엔드 (Backend)**: 레스토랑의 보이지 않는 주방과 식자재 창고. 데이터를 저장하고 가공하며 보안을 책임지는 무대 뒤 공간.
2. **데이터베이스 (Database / DB)**: 절대로 지워지지 않는 디지털 만능 장부.
3. **테이블 (Table)**: 데이터베이스 장부 안의 엑셀 시트 하나. (예: 습관 목록 시트, 사용자 시트).
4. **Row(행) & Column(열)**: 엑셀의 가로줄(데이터 한 건)과 세로줄(속성 이름: 제목, 작성일 등).
5. **기본키 (Primary Key / PK)**: 각 데이터 행을 구별하는 고유한 주민등록번호 (보통 중복되지 않는 UUID 사용).
6. **외래키 (Foreign Key / FK)**: 다른 테이블의 데이터를 가리키는 연결 고리 (예: "이 완료 기록은 3번 습관의 기록입니다").
7. **Supabase (수파베이스)**: 백엔드 개발자 없이도 클릭 몇 번으로 데이터베이스와 회원가입을 5분 만에 무료로 만들어주는 5성급 클라우드 서비스.
8. **BaaS (Backend-as-a-Service)**: 백엔드 서버를 직접 만들 필요 없이 완제품 형태로 빌려 쓰는 서비스 (Supabase, Firebase 등).
9. **API (Application Programming Interface)**: 프론트엔드(손님)와 백엔드(주방) 사이를 오가며 주문을 전달하고 음식을 가져다주는 주문서 전달 통로.
10. **CRUD (크루드)**: 데이터 관리의 4대 기본 동작: Create(생성), Read(조회), Update(수정), Delete(삭제).
11. **RLS (Row Level Security)**: 데이터베이스의 각 줄(Row)마다 자물쇠를 채워, "남의 데이터는 못 보고 내 데이터만 보게" 만드는 강력한 행 단위 보안 규칙.
12. **환경변수 (****`.env.local`****)**: 외부에 노출되면 안 되는 비밀번호나 API 키를 금고처럼 따로 모아 보관하는 비밀 설정 파일.
### [도구, 배포 및 협업 영역]
1. **Git (깃)**: 게임의 세이브 포인트 시스템. 코드가 잘 돌아갈 때마다 시점을 저장해두고 언제든 과거로 돌아갈 수 있는 영구 타임머신.
2. **Commit (커밋)**: 지금까지 작업한 상태를 찰칵 찍어 세이브 파일 1개로 저장하기.
3. **GitHub (깃허브)**: 내 컴퓨터에만 있던 세이브 파일들을 전 세계 어디서나 볼 수 있게 클라우드(은행 금고)에 백업하고 공유하는 사이트.
4. **Cursor (커서)**: AI(Claude, GPT)의 두뇌가 기본 탑재되어 있어 말 한마디로 코드를 짜주는 전 세계 1위 차세대 AI 코딩 에디터.
5. **터미널 (Terminal)**: 마우스 대신 키보드로 컴퓨터에게 직접 명령을 내리는 까만 글씨 창.
6. **npm**: 전 세계 개발자들이 미리 만들어 둔 편리한 무료 코드 부품(라이브러리)들을 다운로드받는 앱스토어.
7. **Vercel (버셀)**: 내 GitHub 저장소를 클릭 한 번으로 연결해 전 세계에 1초 만에 무료 웹사이트 주소로 배포해 주는 클라우드 플랫폼.
8. **PWA (웹 앱)**: 앱스토어 심사 없이 웹사이트를 스마트폰 바탕화면에 진짜 모바일 앱 아이콘으로 설치해 전체화면으로 실행시키는 기술.
