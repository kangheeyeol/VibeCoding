# Chapter 15. AI가 만든 2,000줄짜리 괴물 파일: 스파게티 코드가 생기는 이유
## 1. 🎯 [디렉터 브리핑] 이번 챕터 미션
- AI에게 새로운 기능을 계속 부탁할 때, AI가 기존 코드를 깔끔하게 나누지 않고 하나의 파일(`page.tsx`)에 덕지덕지 이어 붙이는 이유를 밝혀냅니다.
- 코드가 썩어가고 있다는 **3대 위험 신호(Warning Signs)**를 조기에 감지하는 감각을 기릅니다.
---
## 2. 💡 [1분 개념] '10평 원룸에 가구 100개 욱여넣기'
처음에 침대 하나만 있던 10평 원룸은 아주 쾌적합니다.  
하지만 살면서 소파를 넣고, 피아노를 넣고, 헬스기구를 넣고, 옷장을 5개 더 집어넣으면 어떻게 될까요?  
나중에는 발 디딜 틈이 없어서 현관문을 열 수도 없고, 양말 한 짝을 찾으려고 온 방을 뒤집어야 합니다.
AI가 만드는 **'스파게티 코드(누더기 코드)'**가 바로 이 원룸과 같습니다.  
AI는 게으른 본능이 있어서, 여러분이 "방을 따로 만들어줘"라고 명령하지 않으면 가장 편한 방법인 **"기존 파일 맨 밑에 코드 이어 붙이기"**를 선택합니다. 그 결과 파일 하나가 1,000줄, 2,000줄짜리 거대한 괴물 파일이 되어버립니다.
---
## 3. 코드가 썩고 있다는 3대 위험 신호
에디터에서 다음 증상이 나타난다면, 여러분의 프로젝트는 이미 위험 수위에 도달한 것입니다!

| 위험 징후 | 실제 나타나는 현상 | 원인과 위험성 |
| --- | --- | --- |
| **1. 먼지처럼 얇아진 스크롤바** | 에디터 오른쪽 스크롤바가 너무 작아져서 위아래로 한참을 내려야 함 (코드 500줄 초과) | 파일 안에 너무 많은 역할(디자인, 데이터, 애니메이션)이 뒤섞여 있어 AI가 전체 흐름을 놓침. |
| **2. 두더지 잡기 버그** | A 기능을 고쳤더니 멀쩡하던 B 기능이 갑자기 터짐 | 코드끼리 거미줄처럼 복잡하게 얽혀 있어(High Coupling), 하나를 건드리면 전체가 와르르 무너짐. |
| **3. AI 응답 속도 저하** | AI가 답변을 생성할 때 한참을 멈칫거리거나 코드가 중간에 뚝 끊김 | 한 번에 읽고 써야 할 코드 분량이 AI의 한계치를 넘어서서 뇌 과부하가 걸린 상태. |

---
## 4. 왜 AI는 스스로 코드를 정리하지 않을까요?
AI는 자율적인 장기 계획을 세우지 못합니다. AI의 목표는 오직 하나, **"지금 사용자가 던진 질문에 가장 빠르게 답하는 것"**뿐입니다.  
새로운 컴포넌트 파일을 만들고, 경로를 연결하고, import 코드를 정리하는 것은 AI 입장에서 귀찮고 복잡한 일입니다.
그래서 **총괄 디렉터인 여러분이 "멈춰! 이제 방을 나눌 시간이야"라고 명령을 내려주어야만** 합니다.
