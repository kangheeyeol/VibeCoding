- 복잡한 설정 없이, 마우스 클릭 몇 번만으로 완벽한 AI 코딩 환경을 완성합니다.

## 2. 💡 [1분 개념] '조리대(Cursor)'와 '가스레인지 불(Node.js)'
개발 도구를 처음 접하면 이름부터 외계어처럼 느껴집니다. 일상 비유로 이해하면 아주 단순합니다.
- 🍳 **Cursor (커서)**: **'최첨단 조리대'**입니다.  
  칼과 도마, 재료 통이 깔끔하게 정리되어 있고, 내 옆에서 24시간 요리를 도와주는 'AI 수셰프(Sous-chef)'가 내장된 최신식 스마트 작업대입니다. (전 세계 표준인 VS Code를 기반으로 만들어져서 모든 확장 기능을 그대로 쓸 수 있습니다.)
- 🔥 **Node.js (노드)**: **'가스레인지의 불'**입니다.  
  우리가 조리대(Cursor)에서 자바스크립트라는 레시피를 짰을 때, 그것이 실제로 보글보글 끓어서 완성된 요리(웹사이트)로 나오게 해주는 보이지 않는 화력 엔진입니다. 한 번 설치해 두면 우리가 직접 건드릴 일도 거의 없습니다.
---
## 3. 3분 완성 초간단 설치 순서 (Windows & Mac 공통)
### 1단계: 화력 엔진 설치하기 (Node.js)
1. 인터넷 창을 열고 공식 웹사이트 [nodejs.org](https://nodejs.org)에 접속합니다.
2. 화면에 초록색 다운로드 버튼 2개가 보입니다. 그중 왼쪽에 있는 **`LTS (안정적인 버전, 권장)`** 버튼을 클릭합니다.
3. 다운로드된 설치 파일(`.msi` 또는 `.pkg`)을 열고, 복잡한 옵션 변경 없이 **`Next` → `Install` → `Finish`**만 계속 누르면 설치 끝!
### 2단계: 최첨단 스마트 조리대 설치하기 (Cursor)
1. 공식 웹사이트 [cursor.com](https://www.cursor.com)에 접속합니다.
2. 파란색 **`Download for Windows`** (또는 Mac) 버튼을 눌러 설치 파일을 다운로드합니다.
3. 설치가 끝나고 Cursor를 처음 실행하면 초기 설정 창이 뜹니다:
  - **Keyboard 설정**: 기본값인 `VS Code` 선택
  - **Language 설정**: 한국어(Korean)가 편하시다면 한글 언어팩 설치 클릭
  - **Login**: 구글이나 깃허브 계정으로 간편 로그인
---
## 4. 🚨 [비상 대응] 윈도우 사용자가 자주 겪는 초기 에러
- **증상**: 설치했는데 프로그램이 명령어를 인식하지 못한다는 메시지가 뜹니다.
- **원인**: 윈도우에서 환경변수(PATH)가 시스템에 등록되는 과정에서 컴퓨터가 아직 이를 인식하지 못했기 때문입니다.
- **해결책**: **컴퓨터를 한 번만 재부팅(다시 시작)**해 주시면 100% 정상 인식됩니다.
