# Chapter 20. 내 코드를 클라우드에 안전하게 보관하기 (GitHub 연동과 커밋 습관)
## 1. 🎯 [디렉터 브리핑] 이번 챕터 미션
- 내 컴퓨터 로컬에만 보관되어 있던 소중한 프로젝트를 전 세계 개발자들의 공용 금고인 **GitHub(깃허브) 원격 저장소에 동기화(Push)**합니다.
- 노트북에 커피를 쏟거나 노트북을 잃어버려도 언제든 새 컴퓨터에서 1분 만에 내 앱을 불러올 수 있는 클라우드 안전망을 구축합니다.
- 실패하지 않는 1인 개발자를 만드는 **'디렉터의 3대 커밋 황금 습관'**을 정립합니다.
---
## 2. 💡 [1분 개념] 내 방의 금고 vs 은행 대여금고
- **로컬 세이브 (Commit)**: 내 방 책상 밑 금고에 귀중품을 넣어두는 것입니다. 안전하지만, 만약 집에 불이 나거나 도둑이 들면(컴퓨터 고장/분실) 끝장입니다.
- **원격 동기화 (Push to GitHub)**: 은행 본점의 지하 대여금고(GitHub Cloud)에 똑같은 복사본을 보관하는 것입니다. 내 컴퓨터가 박살 나도 은행에 로그인만 하면 내 모든 코드가 1초 만에 살아납니다.
또한 나중에 **Part 9에서 배울 Vercel(웹사이트 무료 출시 플랫폼)은 GitHub에 코드가 올라가 있어야만 클릭 한 번으로 전 세계 사람들에게 배포**할 수 있습니다.
---
## 3. 📋 [실전 가이드] 마우스로 GitHub에 내 코드 올리기 (Sync Changes)
Part 3에서 GitHub 스타터 템플릿의 `Use this template` 기능으로 이미 본인 계정의 저장소를 만들었습니다.  
이제 Cursor와 내 GitHub 저장소를 연결하여 버튼 하나로 동기화합니다.
### Step 1. Cursor에서 GitHub 로그인하기
1. Cursor 에디터 왼쪽 맨 아래의 **톱니바퀴 또는 사람 모양 계정 아이콘**을 클릭합니다.
2. `Sign in with GitHub`를 클릭하여 웹 브라우저에서 GitHub 로그인 및 권한 승인(`Authorize`)을 완료합니다.
### Step 2. 'Sync Changes' 버튼 클릭하기
1. 왼쪽 사이드바의 **소스 제어(****`Ctrl + Shift + G`****)** 창으로 갑니다.
2. 커밋을 마치고 나면 하단에 파란색 **[Sync Changes 1 ↑]** (또는 [Publish Branch]) 버튼이 활성화됩니다.
3. 이 버튼을 클릭하면 세이브 파일이 GitHub 클라우드로 순식간에 날아갑니다.
### Step 3. 내 GitHub에서 확인하기
1. 웹 브라우저를 열고 내 GitHub 저장소(`https://github.com/본인아이디/routinemate`)에 접속합니다.
2. 방금 Cursor에서 남긴 커밋 메시지와 함께 파일들이 최신 시간으로 업데이트되어 있다면 대성공입니다!

## 4. 👑 [디렉터의 3대 커밋 황금 습관]
바이브 코딩을 성공시키는 디렉터와 매번 프로젝트를 폭파시키는 초보자의 차이는 단 하나, **'커밋 습관'**에 있습니다:

| 순번 | 황금 습관 | 이유와 행동 지침 |
| --- | --- | --- |
| **규칙 1** | **기능 하나가 작동하면 무조건 즉시 커밋하라** | 습관 추가 팝업이 예쁘게 떴다면 다른 기능(체크박스) 손대기 전에 바로 커밋! 그래야 다음 작업이 망해도 팝업은 살릴 수 있습니다. |
| **규칙 2** | **고장 난 상태(에러 화면)로는 절대 커밋하지 마라** | 에러가 뜨는 채로 세이브하면 '고장 난 상태'가 세이브 포인트가 되어 되돌릴 기준점이 사라집니다. 에러가 나면 Discard로 돌아가거나 고친 뒤 커밋하세요. |
| **규칙 3** | **오늘 작업을 마칠 때는 무조건 Push(Sync)를 눌러라** | 오늘 하루의 노력을 클라우드에 백업해두지 않고 잠들지 마세요. 내일 무슨 일이 일어날지 모릅니다. |

## 6. 🚨 [비상 대응] 'Push Rejected' 또는 권한 오류가 뜰 때
- **원인**: GitHub 저장소 설정에서 이메일 권한이 맞지 않거나, 원격 저장소와 로컬의 싱크가 일시적으로 어긋난 경우입니다.
- **해결책**:
  1. Cursor 화면 우측 하단 알림창에서 **[Open Git Log]** 대신 **[Pull and Push]** 버튼이 보인다면 클릭합니다.
  2. 만약 해결되지 않는다면 아래 비장의 구원투수(Chapter 20-1)를 활용하세요.
