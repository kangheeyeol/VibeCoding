# Chapter 20-1. [구원투수] 코드가 완전히 꼬였을 때: 챕터별 완성본 브랜치(Chapter Snapshot)로 1초 만에 복구하기
## 1. 🎯 [디렉터 브리핑] 이번 챕터 미션
- 아무리 조심해도 비개발자가 코딩을 하다 보면 되돌리기 시점을 놓쳐 **"에러가 30개씩 뜨고 화면이 먹통이 되는 재앙"**을 만날 수 있습니다.
- 이때 좌절하고 책을 덮는 대신, 저자가 미리 완벽하게 만들어 둔 **각 챕터별 공식 완성본 스냅샷(Snapshot Branch)을 통째로 가져와 1초 만에 복구하는 치트키**를 배웁니다.
---
## 2. 💡 [1분 개념] 모노폴리 게임의 '보너스 복구권'
부루마블이나 모노폴리를 하다가 파산 위기에 처했을 때 게임을 아예 접어버리면 너무 아쉽습니다.  
만약 게임 규칙에 *"파산하면 직전 턴에 1등이 플레이하던 완벽한 상태로 말을 옮겨 탈 수 있는 찬스 카드"*가 있다면 어떨까요?
챕터 스냅샷 브랜치가 바로 그 찬스 카드입니다.  
내가 어디서 코드를 망쳤든 상관없이, **해당 챕터의 공식 완성본 코드를 내 프로젝트 위에 그대로 덮어씌워 즉시 정상 궤도로 합류**할 수 있습니다.
---
## 3. 📋 [실전 가이드] 1초 만에 공식 완성본 스냅샷으로 갈아 끼우기
### 방법 A. 터미널에서 명령어 딱 한 줄로 복구하기 (가장 빠름)
Cursor 하단 터미널(`Ctrl + ~`)을 열고, 복구하고 싶은 챕터 번호에 맞춰 아래 명령어를 복사해 붙여넣고 엔터만 치면 끝납니다.
```bash
# 예시: Part 5(컴포넌트 분리)까지 완벽하게 완성된 코드로 강제 복원하고 싶을 때
git fetch origin
git reset --hard origin/snapshot-part-05
```
> 💡 **명령어 의미**:
> "내 컴퓨터의 엉망진창인 코드를 다 버리고, 공식 서버(origin)에 저장된 `snapshot-part-05` 시점의 깨끗한 완성본 코드로 100% 똑같이 덮어씌워라!"
### 방법 B. 터미널조차 겁난다면? ZIP 파일 다운로드 (초보자 추천)
1. 루틴메이트 공식 GitHub의 [Releases 페이지](https://github.com/kangheeyeol/VibeCoding/releases)로 이동합니다.
2. 원하는 챕터의 `part-05-complete.zip` 파일을 다운로드합니다.
3. 압축을 풀고, 내 프로젝트 폴더 안에 들어있는 파일들을 통째로 덮어쓰기(Replace All)합니다.
4. 브라우저를 새로고침하면 거짓말처럼 에러가 사라지고 완성된 화면이 나타납니다!
