## 2. 💡 [1분 개념] '집짓기'로 이해하는 웹 기술 4총사
```javascript
┌────────────────────────────────────────────────────────┐
│  🏠 집짓기로 이해하는 웹 기술 4총사                     │
├────────────────────────────────────────────────────────┤
│  1. HTML       : 집의 뼈대와 기둥, 벽돌 (골조)         │
│  2. CSS        : 도배, 장판, 페인트, 조명 (인테리어)   │
│  3. JavaScript : 전등 스위치, 도어락, 엘리베이터 (기능) │
│  4. React      : 완제품 조립식 모듈 (방, 욕실 블록)   │
└────────────────────────────────────────────────────────┘
```
- **HTML**: 벽돌을 쌓아 방의 구조를 잡는 뼈대입니다. (버튼이 들어갈 자리, 글자가 들어갈 자리를 만듦)
- **CSS (Tailwind)**: 벽돌 위에 예쁜 에메랄드 페인트를 칠하고 모서리를 둥글게 깎는 인테리어입니다.
- **JavaScript**: 버튼을 눌렀을 때 불이 켜지게 만드는 똑똑한 두뇌와 전기 회로입니다.
- **React / Next.js**: 매번 벽돌을 일일이 쌓지 않고, 이미 완성된 **'스마트 욕실 모듈'이나 '주방 싱크대 모듈'을 레고처럼 툭툭 끼워 맞추는 현대식 조립 공법**입니다.

## 3. 프로젝트 폴더의 핵심 보물 지도
Cursor에서 프로젝트 폴더를 열면 왼쪽에 여러 폴더와 파일이 보입니다. 다른 건 다 몰라도 다음 4가지만 알면 충분합니다!
1. 📂 **`app/`**** (또는 ****`src/`****)**: 
  - 우리가 만든 웹페이지 화면들이 모여 있는 **'진짜 본체'**입니다. 화면을 고치고 싶을 땐 항상 이 폴더 안을 봅니다.
2. 📂 **`public/`**: 
  - 로고 이미지, 아이콘, 폰트 파일 등이 들어 있는 **'사진첩'**입니다.
3. 📄 **`package.json`**: 
  - 우리 프로젝트의 **'재료 구매 영수증'**입니다. 이 프로젝트에 어떤 최신 부품들이 들어 있는지 적혀 있습니다.
4. 🔒 **`.env`**** (환경변수 파일)**: 
  - **절대 남에게 보여주면 안 되는 '비밀 금고'**입니다. 데이터베이스 암호나 API 비밀키가 안전하게 보관되는 곳입니다.
